Better Doubao 设置
v2.1.0 · 按需开启或关闭各增强模块（修改后刷新豆包页面生效）
功能模块开关
侧边栏快捷图标栏与「更多」抽屉
将左侧边栏常用入口收纳为横排图标，并在展开「更多」时以双列抽屉承接，不破坏侧边栏布局。
分类文件夹与极简色彩圆点
用 8px 极简分类圆点替换「最近」列表原生对话图标，支持点击圆点一键归类与彩色文件夹管理。
原生点赞联动定位点标星
点击豆包消息底部的原生「赞 👍」时，自动同步高亮左侧原生快速定位点刻度并收入收藏目录。
Better Doubao 工具栏、语料板与高亮
启用悬浮工具栏（语料板、对话搜索、高亮与收藏、可视化布局与配色定制、JSON 备份恢复）及划词高亮。
多格式对话导出
在顶部导航栏提供 PDF / TXT / Markdown 清爽导出入口。
隐藏顶栏「下载电脑版」按钮
隐藏顶部导航栏的桌面客户端下载推广按钮。
隐藏侧边栏底部「关于豆包」推广区
隐藏侧边栏左下角的「关于豆包」与客户端推广栏。
精简输入框底栏技能按钮
可在豆包页「Better Doubao 工具栏 → ⚙ 界面布局与配色定制」原型图弹窗中直观勾选、添加悬浮快捷胶囊与切换 6 套主题配色。
LaTeX 公式下载与复制
自动识别页面数学公式与 LaTeX 代码块，提供一键复制与 .tex 下载按钮。
数据与隐私说明

所有文件夹、语料、高亮、收藏及扩展设置仅存储在浏览器扩展本地存储（chrome.storage.local）中，不向任何第三方服务器上传。建议在豆包页面的「Better Doubao 工具栏 → 数据备份与恢复」定期导出 JSON 备份。
