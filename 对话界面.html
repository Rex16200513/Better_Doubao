1. after_model(self, state, runtime)

你正在用的方法
  • 执行时机：模型调用完成后（AI 返回回答之后）
  • 参数：
    • state：当前完整的状态对象（包含 messages + 你的 total_tokens/last_model）
    • runtime：Agent 运行时的上下文信息（一般用不到）
  • 你的用途：读取 AI 消息的 token → 累计 → 更新状态

2. wrap_model_call(self, request, handler)

你没用到的钩子方法
  • 执行时机：模型调用之前（发送请求给大模型之前）
  • 参数：
    • request：ModelRequest 对象（包含要发给模型的所有入参：prompt、模型名、温度等）
    • handler：模型调用的执行函数（你可以手动调用它，触发模型请求）
  • 用途：修改请求参数（比如动态改模型、加 prompt、拦截请求）

一句话总结

✅ after_model = 模型调用后 → 拿 state 做统计 / 更新（你统计 Token 用这个）
✅ wrap_model_call = 模型调用前 → 改 request 参数
你现在的 Token 统计逻辑，用 after_model 是完全正确的！
